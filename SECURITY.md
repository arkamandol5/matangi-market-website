# Security policy

## Supported version

Security updates apply to the latest version on the `main` branch.

## Reporting a vulnerability

Please use GitHub’s private vulnerability reporting feature on this repository
to report a suspected security issue. Include:

- a description of the issue and its potential impact;
- the affected page, component or dependency;
- clear reproduction steps; and
- a suggested remediation, if known.

Please do not disclose suspected vulnerabilities in public issues, discussions
or pull requests. Reports will be reviewed as promptly as practical for this
early-stage company website.
